# فيزياء كومنت · Comnt Physics

Interactive physics lessons for Egyptian Baccalaureate grade 11 (الصف الثاني الثانوي), Chapter 1:
Lessons 1-1 to 1-8: velocity vectors, projectiles, torque, equilibrium of forces, power and efficiency, momentum and impulse, conservation of momentum. Plus a games tab and a basics tab.

Static site, no build step. It installs as an app (PWA) on Android, iOS, tablets and desktop and works offline after the first visit.

- `index.html`: the whole app (generated from the lesson sources)
- `manifest.webmanifest`, `sw.js`, `icons/`: install and offline support
